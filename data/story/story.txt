#  쓰는 법
#   - [구간] 아래에 「이름: 대사」를 한 줄에 하나씩 쓰면, 그 순간에 대화창으로 차례로 나옵니다.
#       성기사: 여기가 초록 들판인가…
#       슬라임 킹: 꾸르르…!
#   - 이름 없이 대사만 쓰면 이름 · 초상화 없이 나옵니다 (해설용).
#   - 빈 구간은 게임에 아무것도 나오지 않습니다. 쓰고 싶은 곳만 채우면 됩니다.
#   - # 로 시작하는 줄은 메모라서 게임에 나오지 않습니다.
#   - 대사가 나오는 동안 게임은 멈추고, Enter 키로만 넘깁니다. 대화창 오른쪽 위 [스킵] 버튼을 누르면 그 대화를 끝까지 건너뜁니다.
#   - 한 번 본 대사는 같은 모험에서 다시 나오지 않습니다 (새 게임을 시작하면 다시 나옴).
#
#  이름 바꿔 주는 말
#   - 보스: 대사   → 「보스」가 그 구간 스테이지의 보스 이름과 초상화로 바뀝니다
#                    ([3스테이지 …] 이면 원소의 거신 아르케온, [히든 …] 은 고대 드래곤 아르케,
#                     [최종장 등장] 은 상인, 그 밖의 [최종장 …] 은 멀티버스의 주인)
#   - 용사: 대사   → 「용사」가 플레이어가 새 게임에서 지은 용사의 이름으로 바뀝니다 (초상화는 주인공)
#                    대사 안의 「용사」도 그 이름으로 바뀝니다. 이름을 안 지으면 그대로 「용사」.
#
#  초상화 (얼굴 그림)
#   - 이름이 「성기사」 「주인공」 「나」 이면 주인공, 「상인」이면 야영지 상인,
#     보스나 몬스터 이름(예: 슬라임 킹, 대천사 가브리엘)이면 그 캐릭터의 그림이 자동으로 나옵니다.
#   - 그림을 바꾸고 싶으면 맨 위에 이렇게 씁니다:
#       @초상화 성기사 = res://assets/sprites/characters/내그림.png
#   - 표정: 이름 뒤에 [표정]을 붙이면 그 표정 그림으로 나옵니다 (이름은 그대로). 평소 얼굴이 잠깐 보였다가 바뀝니다.
#       상인[미소]: 좋은 포션이 많이있답니다~~~?
#   - [최종장 등장] 뒤의 최종장 구간에서는 「상인」의 초상화가 멀티버스의 주인으로 나옵니다.
#
#  넣고 싶은 게임 장면
#   - @장면: 으로 시작하는 줄에 원하는 장면을 적어 두세요. 게임에는 나오지 않고, 나중에 그대로 구현합니다.
#   - 대사 사이에 적으면 「그 대사 다음에 이 장면」이라는 뜻으로 순서도 그대로 따릅니다.
#       [3스테이지 보스 토벌]
#       수문장: 크윽… 업화가…
#       @장면: 화면이 하얗게 번쩍이고, 수문장의 뿔이 부러져 바닥에 떨어진다
#       성기사: 끝났다.
#   - 만들어진 장면은 @연출: 이름 줄로 들어갑니다 (그 자리에서 장면이 나오고 다음 대사로 넘어감).
#       @연출: 장비빛남    용사가 금빛으로 빛나고 가진 장비들이 둘레에 떠올라 빛남
#       @연출: 각성        화면이 번쩍이고 충격파가 퍼짐
#   - 대사가 길면 대화창 한 칸에 들어가는 만큼씩 나눠서 나옵니다.
#
#  구간 종류
#   [N스테이지 도착]      N스테이지 야영지에 처음 도착했을 때
#   [N스테이지 보스 등장]  N스테이지 보스방에서 보스가 나타났을 때
#   [N스테이지 보스 토벌]  N스테이지 보스를 쓰러뜨렸을 때
#   [N스테이지 상인]      N스테이지에서 상인에게 처음 말을 걸었을 때 (없으면 [상인])
#   [상인]                상인에게 말을 걸 때마다 (공통 — 그 스테이지의 [N스테이지 상인]이 있으면 처음 한 번은 그쪽)
#   [히든 보스 등장] [히든 보스 토벌]
#   [최종장 등장]         상인이 보스방에 나타났을 때 — 쓰면 기본 고백 대사 대신 이 대사가 나옴
#   [최종장 정체]         상인이 멀티버스의 주인으로 변한 직후
#   [최종장 2페이즈]      멀티버스의 주인이 체력 2/3 에서 각성했을 때 (각성 연출 뒤)
#   [최종장 토벌]         멀티버스의 주인을 쓰러뜨렸을 때
#   [엔딩]                엔딩 화면이 시작될 때
#
#  Windows 버전: Crusader.exe 와 같은 폴더에 이 파일(story.txt)을 두면 다시 빌드하지 않고도 대사가 바뀝니다.
