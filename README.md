# 크루세이더 — 세피리아(Sefirah) 스타일 탑뷰 액션 (Godot 4)

2D 도트 그래픽 탑뷰 액션 게임의 **바로 실행 가능한** Godot 4 프로젝트입니다.

- **타이틀**: 전사와 몬스터가 싸우는 일러스트 배경 + **난이도 선택 (노멀 / 하드 / 베리하드)** → **조작 안내** → 모험 시작
- **맵 흐름**: 야영지(상인) → 텔레포트 → 사냥터(처치 목표 달성 시 **보스방 봉인 해제**) → 보스방 → **보물상자** + 다음 스테이지 텔레포트 → … 60스테이지 보스 토벌 시 **엔딩** (숨겨진 **히든 던전**도 있음) → 난이도 선택 화면
- **장비 칸**: 무기 3칸(**검 / 활 / 지팡이**, 1·2·3·Q 로 전환) · 방어구 4칸(**방패 / 투구 / 갑옷 / 신발**) · **장신구 3칸**(**팔찌**: 치명타 피해·방깍 / **반지**: 치명타 확률·공격력 / **펜던트**: 최대 체력·체력 재생)
- **인벤토리**(I / Tab): 장비 칸 + 가방 + 능력치 요약. 상인에게 **장비 판매** 가능
- **회복 포션**: 상점에서 여러 개 구매(종류별 최대 5개), **H** 키로 잃은 체력에 맞는 포션 자동 사용
- **무기 특화** — 검: 가장 높은 공격력의 부채꼴 베기 / 활: 공격력은 낮지만 **빠른 공속 + 방어력 관통(방깍)**, 시위 당겨 발사 / 지팡이: 영창 중 조준한 곳에 **범위 원** 표시 → 지팡이마다 다른 **범위 마법** (서리 폭발·점액 웅덩이·업화·거대 슬라임·별똥별)
- 모든 잡몹·보스에 **방어력** — 방어력만큼 피해가 줄고, 무기·팔찌의 **방깍**만큼 무시 (최소 피해 20% 보장)
- 등급(일반·희귀·레어·전설)이 높을수록 공격력·방어력뿐 아니라 **이펙트도 화려**
- 방패 가드 · 퍼펙트 가드(탄 반사, 적 기절 — 판정 0.3~0.45초, **방패가 금빛일 때**) · 가드 브레이크

## 팀원과 함께 플레이하기

| 방법 | 대상 | 하는 법 |
| --- | --- | --- |
| **Windows 실행 파일** | Godot 없이 바로 플레이 | `Crusader_Windows.zip` 압축 해제 → `Crusader.exe` 더블클릭 (파란 경고창이 뜨면 [추가 정보] → [실행]) |
| **웹 버전** | 링크로 브라우저에서 플레이 | `Crusader_Web.zip` 을 [itch.io](https://itch.io) 에 HTML5 게임으로 업로드 (또는 GitHub Pages / 정적 웹 서버에 올리기) |
| **Godot 프로젝트** | 같이 개발 | GitHub 에서 Code → Download ZIP (또는 `git clone`) → Godot 4.3+ 로 `project.godot` Import |

직접 빌드하기: Godot 에디터 → 프로젝트 → 내보내기 → `Windows Desktop` / `Web` 프리셋 (`export_presets.cfg` 포함, 처음 한 번 "내보내기 템플릿 관리"에서 템플릿 다운로드 필요).
헤드리스: `godot --headless --path . --export-release "Windows Desktop" build/windows/Crusader.exe`

**Windows 실행이 안 될 때** (`Crusader_Windows.zip` 안의 `HOW_TO_RUN.txt` 와 같은 내용)

1. zip 을 **압축 풀기** 한 뒤 실행 (zip 안에서 바로 실행하면 안 될 수 있음)
2. 파란 「Windows의 PC 보호」 창 → **[추가 정보] → [실행]**
3. 백신이 `Crusader.exe` 를 지웠다면 검역소에서 복원 + 예외 추가
4. 그래도 안 되면 `run_opengl.bat`(다른 그래픽 방식) 또는 `run_debug.bat`(오류 기록 `crusader_log.txt` 저장)

> Windows 에서는 그래픽 드라이버 호환성을 위해 OpenGL 대신 **ANGLE(Direct3D 11)** 로 그립니다
> (`project.godot` → `rendering/gl_compatibility/driver.windows="opengl3_angle"`). 도우미 파일 원본은 `tools/windows_extra/`.

> 한글 폰트는 게임에 내장되어 있습니다 (갈무리 Galmuri11, SIL OFL 1.1 — `assets/fonts/`). 그래서 웹이나 한글 폰트가 없는 PC 에서도 글자가 깨지지 않습니다.

## 실행 방법

1. Godot 4.3+ 실행 → **Import** → 이 폴더의 `project.godot` 선택
2. `F5` → 타이틀(`res://scenes/title/title.tscn`) → 난이도 선택 → 조작 안내 → **모험 시작**

| 입력 | 동작 |
| --- | --- |
| `WASD` / 방향키 | 이동 |
| 마우스 이동 | 조준 |
| 마우스 왼쪽 (누르고 있기) | 공격 — 검: 휘두르기 / 활: 시위 당겨 발사 / 지팡이: 영창(조준한 곳에 범위 원) 후 마법 시전 |
| 마우스 오른쪽 / `F` (누르고 있기) | 방패 가드 — 올린 직후(방패가 금빛으로 빛나는 동안) 맞으면 퍼펙트 가드 |
| `Space` / `Shift` | 대시 (무적) |
| `1` / `2` / `3`, `Q` / 마우스 휠 | 무기 칸 전환 (검 · 활 · 지팡이) |
| `H` | 회복 포션 사용 (잃은 체력에 맞는 포션 자동 선택) |
| `E` | 상호작용 — 상인 · 텔레포트 · 보스문 · 보물상자 |
| `I` / `Tab` | 인벤토리 |
| `ESC` | 창 닫기 |
| `R` / `T` | 쓰러졌을 때 다시 시작(같은 난이도) / 타이틀로 |

(비늘 위치는 스테이지마다 고정 — `StageManager.get_dragon_scale_spot()`)

### 장비 칸

| 칸 | 개수 | 내용 |
| --- | --- | --- |

| 일반 | 가죽 팔찌 (+15%, 1) | 구리 반지 (+3%, +5%) | 나무 펜던트 (+15, 0.5) |
| 희귀 | 은 팔찌 (+25%, 2) | 루비 반지 (+6%, +8%) | 사파이어 펜던트 (+30, 1.0) |
| 레어 | 흑요석 팔찌 (+40%, 4) | 핏빛 루비 반지 (+10%, +12%) | 수호자의 펜던트 (+50, 1.5) |
| 전설 | 용린 팔찌 (+60%, 7) | 별의 반지 (+15%, +20%) | 생명의 펜던트 (+80, 2.5) |

1타 데미지 = `무기 공격력 × (1 + 반지 공격력)`, 치명타 확률 = `무기 + 반지`, 치명타 배율 = `무기 + 팔찌`.
몬스터가 받는 피해 = `max(데미지 − max(0, 몬스터 방어력 − 방깍), 데미지의 20%)` (방깍 = 무기 + 팔찌, 폭발에도 적용).
플레이어 방어력 = 방패 + 투구 + 갑옷 + 신발 (모든 피해에서 차감, 최소 1).
**지속 피해(화상)** 도 방어력이 높을수록 줄어듭니다: 실제 피해 = 기본 피해 × 15 / (15 + 방어력) (방어력 15 에서 절반, 최소 1).
화상은 가드·대시 무적으로 막을 수 없으므로 **펜던트의 체력 재생**으로 버팁니다. (앞으로 추가될 지속 피해 기믹도 같은 방식)

**와이번 · 서큐버스 · 옥좌 잃은 왕 기믹 구현 메모**
- 공격 종류: `Enemy.HitKind` (MELEE / BOW / MAGIC). `Enemy.airborne` 이 켜지면 `can_be_hit_by()` 가 BOW 만 허용 — 근접 판정·투사체·폭발·지팡이 장판이 모두 이 검사를 거칩니다. 공중에서는 몸통 접촉 피해도 없습니다.
- 죽음의 낙인: `Player.add_death_mark()` — 적의 `death_mark_on_hit` 이 있으면 몸통·탄·장판에 맞을 때 쌓입니다.
- 족장의 함성: `BossOrcKing.rally_minions()` — `register_minion()` 으로 받은 자기 부하에게만 버프 (`Enemy.base_tint` 로 붉은 색조).
- 매혹: `Player.apply_charm(시간, 매혹한 적)` — 이동·공격·가드·대시·포션 입력이 막히고 매혹한 적 쪽으로 천천히 끌려갑니다. 적 탄에 `charm_duration` 을 주면 맞았을 때 걸립니다.
- 왕관: 별도의 적(`CrownEnemy`)으로 소환되어 왕의 머리 위를 따라다닙니다. 왕은 `register_minion()` 으로 왕관을 받아 체력을 정하고, 왕관이 죽으면 가호가 꺼집니다.
- 6~60스테이지 보스와 히든 보스는 공용 기반 `PatternBoss`(추적 ↔ 시전, 패턴 순서, 2페이즈, 머리 위 상태 문구)를 상속합니다.

**11~60스테이지 · 히든 기믹 구현 메모**
- 보스 부위: `BossPart` (키메라 꼬리 · 마도코어 · 크라켄 촉수 · 도플갱어 거울). 보스가 `request_summon()` 으로 만들고 `register_minion()` 에서 체력·위치를 정합니다. `follow_boss` 면 보스를 따라다니고, `relay_ratio` 가 있으면(마도코어) 자기 체력 없이 맞은 공격을 그 배율로 보스에게 넘깁니다.
- 회전 레이저: `LaserSweep` — 예고선 뒤 한 줄기 레이저가 `sweep` 만큼 회전, 선분과의 거리로 플레이어 판정 (무적시간·대시·가드 적용).
- 독: `Player.apply_burn(피해, 시간, poison = true)` — 화상과 같은 지속 피해(방어력으로 감소), 상태 표시와 색만 「독」. 적은 `burn_is_poison`.
- 시간 역행: `BossArkeos` 가 0.2초마다 (보스 체력, 플레이어 위치)를 기록하고 `rewind_seconds` 전 기록으로 되돌립니다.
- 그리핀 날개: `BossPart` 2개. 날 때 그리핀이 매 프레임 날개의 `airborne`·위치를 맞춰 날개도 활로만 맞습니다. 방어력 감소는 `Player.apply_armor_break()`.
- 꼭두각시: `Player.set_puppet(조종자, 구속력, 남은 실)` — 이동 입력이 조종자의 `get_puppet_pull()` 방향과 구속력 비율로 섞입니다. 스위치는 `PuppetSwitch`.
- 상단/하단: `StormField` (보스방을 가로로 반 나눈 영역 · 예고 · 연출), 판정은 `is_in_zone()`.
- 대마법 영창: 영창 중 받은 피해를 모아 `interrupt_ratio` 를 넘으면 끊김. 메테오는 `Player.take_unblockable_hit(…, dodgeable = false)`.
- 쌍둥이: `BossTwin` (role = SOL / LUNA). 치명타를 맞으면 `_die()` 대신 `_fall()`, 짝이 쓰러진 상태일 때만 함께 `_die()`.
- 냉기·눈보라: `Player.set_chill()`(표시) · `Player.apply_push()`(이번 프레임만 미는 힘) · `IcePillar.shelters()`.
- 어둠: `assets/shaders/darkness.gdshader` (빛 원 최대 8개를 뚫은 어둠) + `AbyssTorch`.
- 흡혈: `BossVampire` 의 핏줄기는 거리로만 판정 (`drain_range`). 독의 포션 감소는 `GameManager.potion_heal_multiplier` (Player 가 독 상태일 때 0.5).
- 독안개: `PoisonFog` — 안전한 원이 `fill_time` 동안 줄어들고, 독샘이 부서지면 `recede()`.
- 잠행: `BossScorpion` 이 숨어 있는 동안 `can_be_hit_by()` 가 모두 false, `take_damage()` 도 무시. 막힌 공격 문구는 `Enemy.immune_text`.
- 열·과열: `BossTemos.cast()` 마다 `add_heat()`, 냉각 속도는 살아 있는 냉각수 기계(`BossPart`) 수에 비례, 과열 중엔 `cast()` 가 막힘.
- 티탄 엄폐: `CoverRock`(StaticBody2D, WORLD 레이어) · `ThrownBoulder`(날아가며 엄폐 바위 → 플레이어 순으로 거리 판정, `Player.take_unblockable_hit()`).
- 삼키기: `Player.apply_root(시간, 문구)` — 이동·대시만 막고 공격은 허용 (`release_root()` · `is_rooted()`). 위벽은 `BossPart`(follow_boss = false).
- 환각: `NightmareIllusion`(Enemy, 충돌 마스크 0 · Shadow 노드 숨김 · 맞으면 흩어짐). 진짜는 환각 중 `_chase_velocity()` 로 환영과 똑같이 맴돎.
- 수면: 기존 매혹(조작 불가)과 같은 처리, `ProjectileSpec.charm_label = "수면"` 으로 문구만 다름.
- 정령핵 · 바닥 붕괴: 핵은 `BossPart` 4개 (원소별 가호는 `BossGaia._update_blessings()`), 바닥은 `CollapseField`(3×3 구역 · `warn()` · `collapse()` · `is_in_tile()`).
- 바람: `WindField` (정적 `WindField.active`) — `Projectile` 이 매 프레임 `WindField.get_wind_at()` 으로 가속도를 받아 속력은 유지한 채 방향만 휨. 회오리는 `Tornado`.
- 돌기둥: `StonePillar`(CoverRock 상속, `stone_pillars` 그룹). 돌진 중 거리로 충돌 판정 → `_crash()`.
- 빙판: `IceFloor` → `Player.mark_slippery()` (매 프레임, 가속·마찰 ×0.12). 부패: `Player.apply_decay()` → `GameManager.potion_heal_multiplier = 0` (포션 사용 자체를 막음), 탄은 `ProjectileSpec.decay_duration`, 장판은 `AoeStrike.decay_duration`.
- 역린: `BossVerdan.is_behind()` — 바라보는 방향(시전 중엔 고정)의 반대쪽에 플레이어가 있으면 배율 피해.
- 불사: `BossHelicion.take_damage()` 에서 치명타를 `_fall()` 로 바꿈, 영혼(`BossPart`)이 죽으면 그때 `_die()`.
- 고대 용언: `DragonRunes`(룬 원 4개 · `safe_contains()`). 히든 던전 흐름은 `StageManager` 의 「히든 던전」 구역 (`hidden_stage` = `data/stages/stage_hidden.tres`, 비늘 = `DragonScale`, 기록 = `GameManager.dragon_scales` / `hidden_cleared`).
- 천칭: `JudgementScale` (좌우 절반 · 무게 · 예고), `BossSeraphine.take_damage()` 에서 실제로 깎인 체력을 플레이어가 선 쪽에 올림. 성흔: `Player.apply_stigma()` → `potion_heal_multiplier = -1` (`use_potion()` 이 회복 대신 피해), 탄은 `ProjectileSpec.stigma_duration`.
- 신앙: `BossAstaroth` 가 매 프레임 `Player.set_faith()` → `GameManager.faith_damage_bonus` (무기 피해 굴림에 곱해짐). 광신화 = `apply_charm(…, "광신")`. 저주의 땅 = `GroundZone.Kind.CURSE`.
- 청동 못·물웅덩이: 못은 `BossPart`(follow_boss · mirror_x), 출혈·새 못 타이머는 기절 중에도 흐르도록 `BossTalos._physics_process()`. 물웅덩이 = `WaterPool`.
- 미궁: `Labyrinth`(StaticBody2D 벽 · `plan()` / `warn()` / `hits_wall()`), 실 = `AriadneThread`(`is_on_thread()` 는 선분 거리).
- 무기 도둑: `GameManager.steal_active_weapon()` / `return_stolen_weapon()` — 훔친 무기는 무기 칸·가방에서 빠졌다가 돌아옴. `StageManager._setup_stage()` 에서도 돌려받는 안전장치.
- 히드라: 머리 자리 9개(`BossHydra._slots`), 머리 = `BossPart`, 잘린 목 = `HydraStump`(맞으면 `on_stump_hit()`), 재생 타이머는 기절 중에도 흐름. 성화대 = `Brazier` → `Player.apply_fire_enchant()` / `has_fire_enchant()`.
- 소리 추적: `GameManager.player_attacked` 시그널 + 대시 → `BossPolyphemus.hear()`, 양 = `Sheep`(공격하지 않는 적, `hides()`).
- 리라 = `Lyre`(`song_finished`), 케르베로스 머리 = `BossPart.relay_ratio`(잠들면 2.0) → `take_weak_point_hit()`.
- 소용돌이 = `Whirlpool`(`apply_push` · 중심 피해), 스킬라는 가장자리 둘레를 따라 이동(`_to_perimeter` / `_from_perimeter`).
- 상승 기류 = `UpdraftPad`, 거미줄 = `WebPatch`, 보물 = `GameManager.key_items` (`KEY_ITEM_NAMES`).
- 용광로 = `MoltenChannels`(`warn()` / `pour()` / `is_in_flow()`), 담금질은 체력 구간 → `BossHephaestus.begin_forge()`, 그물 = `BossPart` + `Player.apply_root()`.
- 51~60: 집어 드는 물건(돌 · 황금 양털 · 생명의 장작) = `CarryItem`(맞으면 떨어뜨림, `picked_up` 시그널), 아르고호 · 화로 = `FieldProp`, 황금 사슴 = `GoldenHind`(플레이어에게서 달아남).
- 때리면 반응하는 물건(청동 징 · 시칠리아의 바위)은 `BossPart.relay_ratio` 로 `take_weak_point_hit()` 를 받아 몇 번째인지 구분합니다 (피해는 넘기지 않음).
- 「공포」는 `Player.apply_charm(시간, null, "공포")` — 끌려가지 않는 행동불능, 상태 표시 「행동불능」. 마르스가 쓰러지면 `release_charm()`.
- 보스가 쓰러지면 아직 터지지 않은 예고 장판(`AoeStrike`, `aoe_strikes` 그룹)도 함께 사라집니다.
- 따라하기: `GameManager.player_attacked` 시그널 (플레이어가 공격을 내보낼 때마다) 을 도플갱어가 받아 같은 종류의 공격을 합니다.

## ⚠️ Node vs Node2D – "Function not found in base self" 를 원천 차단한 방법

`get_global_mouse_position()`, `global_position`, `to_local()`, `get_world_2d()` 등은 **CanvasItem / Node2D 의 함수**입니다.

| 스크립트 | 상속 | 위치/마우스 함수 사용 |
| --- | --- | --- |
| `player.gd` | CharacterBody2D | ✅ 여기서만 `get_global_mouse_position()` 호출 |
| `attack_controller.gd`, `guard_controller.gd` | **Node** | ❌ `player.get_aim_direction()` 등 **타입이 지정된 Player 참조**로만 |
| `stage_manager.gd` | **Node** | ❌ `Room.get_bounds()`, `Marker2D.global_position`, `entities_root.to_local()` 처럼 Node2D 참조로만 |
| `projectile_pool.gd`, `game_manager.gd` | **Node** | ❌ 데이터만 다룸 |
| `fx.gd`, `item_db.gd`, `item_row.gd`, `elements.gd` | static 헬퍼 | ❌ 위치는 인자로 받음 |
| `room.gd`, `interactable.gd` 계열, `enemy.gd` 계열, `projectile.gd`, `pickup.gd`, `aoe_strike.gd` | Node2D / Area2D | ✅ |

- 모든 참조가 **정적 타입**이라 잘못된 호출은 에디터에서 즉시 빨간 줄로 잡힙니다.
- 충돌 콜백 안의 물리 상태 변경(`monitoring`, Area2D 추가 등)은 전부 `set_deferred` / `call_deferred`.
- 타입이 지정된 배열(`Array[WeaponData]` 등)에 다른 타입을 넣어 검색하지 않도록 종류를 먼저 확인합니다.
- GDScript 경고를 전부 **에러로 취급**하는 설정에서도 모든 스크립트가 통과합니다.

## 확장 가이드

  `shoot()`, `telegraph_strike()`, `request_summon()` 헬퍼 사용.
- **새 스테이지**: `StageData` (.tres) 를 만들고 `main.tscn` 의 `StageManager.stages` 에 추가.
- **새 상호작용 오브젝트**: `extends Interactable` 후 `_interact()` 오버라이드.
- **방 크기/배치**: `main.tscn` 의 `Rooms/*` 의 `size`, `Markers/*` 위치만 바꾸면 벽·카메라 경계·스폰 영역이 따라갑니다.
