크루세이더 — 실행 방법 (Windows 10 / 11, 64비트)

1. zip 파일을 반드시 "압축 풀기(모두 추출)" 한 뒤 실행하세요.
   (zip 안에서 바로 더블클릭하면 실행되지 않을 수 있습니다)

2. Crusader.exe 를 더블클릭합니다.

3. "Windows의 PC 보호" (파란 창) 가 뜨면
   → [추가 정보] 클릭 → [실행] 클릭
   (서명되지 않은 개인 제작 게임이라 처음 한 번 뜨는 경고입니다)

4. 백신(V3, 알약, Windows 보안 등)이 Crusader.exe 를 지웠다면
   → 백신의 "검역소/치료 기록"에서 복원하고 예외로 추가한 뒤 다시 풀어 주세요.

그래도 실행되지 않으면
- run_opengl.bat : 다른 그래픽 방식(OpenGL)으로 실행해 봅니다.
- run_debug.bat  : 오류 기록을 crusader_log.txt 로 저장합니다.
                   이 파일을 보내 주시면 원인을 바로 찾을 수 있습니다.
- 그래픽 드라이버를 최신으로 업데이트해 보세요.

웹 버전(Crusader_Web.zip)은 설치 없이 브라우저로도 실행할 수 있습니다.
