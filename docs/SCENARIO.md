# 크루세이더 시나리오 — 3막 + 최종장

> 한 줄 요약: 낯선 세계에 떨어진 성기사가 백 개의 세계를 넘으며 진실에 다가가고, 처음부터 곁에서 장비를 팔던 **상인**이 이 모든 것을 꾸민 **멀티버스의 관리자**였음을 알게 된다. 그를 쓰러뜨려 세계들을 돌려보내지만, 빈 관리자의 자리에는 곧 누군가가 앉는다.

- 표시: ✅ 지금 대본(`data/story/story.txt`) · 게임에 있음 / ➕ 새로 넣으면 좋은 장면 (제안)
- 대본 구간 이름은 `[N스테이지 도착]` · `[N스테이지 보스 등장]` · `[N스테이지 보스 토벌]` · `[N스테이지 상인]` · `[최종장 …]` · `[엔딩]`

---

## 바탕 설정

| 항목 | 내용 |
| --- | --- |
| 무대 | 상인(멀티버스의 관리자)이 여러 세계를 통째로 끌어와 이어 붙인 **투기장**. 세계마다 주인(보스)이 있고, 포탈로 이어져 있음 |
| 상인의 정체 | 수많은 세계를 지켜보다 지루함에 썩어 가던 존재. 세계끼리 싸우게 하는 「연극」을 열고, 마지막엔 자기 자신까지 등장인물로 올려 **자기를 이길 존재**를 기다림 |
| 용사 | 하늘에서 떨어진 이름 없는 성기사. 첫 장비를 「선물」로 받음 — 사실은 관리자가 고른 다음 배우 |
| 이전 도전자 | 용사보다 먼저 같은 길을 걸은 성기사. 끝에서 상인에게 막혀 쓰러졌고, 녹슨 갑옷과 일지만 남음 |
| 보스들 | 끌려온 세계의 주인들. 대부분 그자에게 맞섰다가 졌고, 「그자를 이길 자」를 기다리며 10스테이지마다 신화 장비를 맡김 |
| 반복 상징 | **연극 · 손님 · 선물 · 관객** (상인의 말버릇) / **주시하는 시선** / **녹슨 갑옷과 일지** |

### 용사의 마음 흐름
감사(1막) → 의심(2막) → 확신과 각오(3막) → 결단(최종장) → 끝나지 않은 싸움(엔딩)

### 상인의 가면 흐름
친절한 장사꾼(1막) → 말실수 · 지나친 칭찬(2막 앞) → 관객 같은 말투(2막 뒤 ~ 3막 앞) → 대놓고 즐김(3막) → 정체(최종장)

## 1막 「낯선 하늘」 — 1 ~ 35스테이지 (판타지 세계)

**막이 끝날 때 용사가 아는 것**: 이 세계들은 원래 한곳에 있던 게 아니다. 누군가 나를 보고 있다. 나보다 먼저 온 사람이 있었다.

## 2막 「신들의 증언」 — 36 ~ 80스테이지 (천상의 법정 · 그리스 신화)

**막이 끝날 때 용사가 아는 것**: 이 싸움을 즐기는 관객이 있다. 그자의 기운이 내 장비에 묻어 있다. 처음 받은 검을 누가 주었는지.

### 남겨 둔 수수께끼 (후속작 · DLC 재료)
- **관리자의 자리에 앉은 자는 누구인가** — 후보: ① 상인이 「다음 배우」로 남겨 둔 또 다른 존재 ② 일지를 쓴 이전 도전자(살아 있었다?) ③ 상인을 만든 더 위의 관리자. 지금 엔딩은 셋 다 열어 둠 (붉은 두 눈만 보임)
- **용사는 어디서 왔는가** — 처음 떨어진 하늘의 정체는 밝히지 않음

## 넣는 방법
- ✅ 는 이미 들어가 있음. ➕ 는 `data/story/story.txt` 의 같은 이름 구간에 한 줄씩 넣으면 바로 게임에 나옴 (Windows 빌드는 exe 옆 story.txt 만 바꿔도 됨).
- 화면 연출이 필요한 곳은 `@장면: 설명` 으로 적어 두면 구현함. 지금 있는 연출: `하늘에서떨어짐` · `선물` · `도전자의흔적` · `장비빛남` · `각성`.
