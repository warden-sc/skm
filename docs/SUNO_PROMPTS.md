# Suno 프롬프트 — 사냥터 배경음 16곡 · 보스 음악 7곡

곡마다 Suno **Custom 모드 · Instrumental 켜기**로 아래 세 칸을 그대로 복사해 넣으면 됩니다.
- **Title** = 파일 이름 (다운로드한 파일 이름이 그대로 이것이 되게) — 이 이름 그대로 보내 주면 게임에 바로 연결합니다.
- **Style of Music** = 공통 머리말 + 그 곡만의 문구 (이미 이어 붙여 둠)
- **Lyrics** = 곡 구성 태그 (사냥터용 · 보스용 두 가지)

넘길 때: 곡마다 마음에 드는 결과 1개만 WAV(안 되면 MP3)로 받아 이름 그대로 한 폴더 → zip. 다시 만든 곡은 이름 끝에 `_v2`. 일부만 먼저 보내도 됩니다.
받으면: 음량 맞추기 · 반복 구간 잡기 · OGG 변환 · 스테이지/보스 연결 · 곡 바뀔 때 부드럽게 · 설정에 「배경음 음량」.
